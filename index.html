Baixar o TranscribaVersão portátil · 183 MB · não precisa instalar

Prefere instalar com atalho no menu Iniciar? Baixe o instalador (126 MB).

Windows 10 ou 11, 64 bits · placa NVIDIA opcional (deixa bem mais rápido)

Como começar

  1. Extraia a pastaClique com o botão direito no arquivo baixado e escolha "Extrair tudo". Não abra o programa de dentro do .zip.
  2. Abra o Transcriba.exeNa primeira vez, o Windows pode mostrar "O Windows protegeu o computador". Clique em "Mais informações" e depois em "Executar assim mesmo".
  3. Arraste os arquivos e clique em TranscreverNa primeira transcrição, o programa baixa o modelo de voz uma vez só (de 150 MB a 1,6 GB). Depois, funciona sem internet.

A fila de arquivos, o que está sendo transcrito agora e o texto aparecendo ao vivo.

Privado

Tudo acontece no seu computador. Suas gravações e os textos não são enviados a ninguém.

Em lote

Uma pasta inteira de uma vez. Ele avisa quando termina e não deixa o computador dormir no meio.

Pronto para usar

Texto corrido (.txt), legendas (.srt) ou texto com marcas de tempo. MP3, MP4, M4A, WAV, OGG do WhatsApp e outros.

Perguntas

É grátis mesmo?
Sim, e sem limite. Se o Transcriba te ajudar, dá para apoiar uma vez só pelo Pix, dentro do próprio programa. Não é obrigatório.
Precisa de internet?
Só na primeira transcrição, para baixar o modelo de voz. Depois, funciona offline.
Fica bom com áudio misturado em inglês?
Sim. Ele detecta o idioma e mantém as citações em outro idioma. Na qualidade "Preciso", o resultado é o melhor.
Meu computador é fraco. Funciona?
Funciona, mais devagar: sem placa NVIDIA, uma hora de áudio pode levar perto de uma hora. Deixe rodando e vá fazer outra coisa.
Por que o Windows avisa ao abrir?
O aviso aparece com programas que não têm assinatura digital paga. O Transcriba é de um desenvolvedor independente. O código não se conecta a nada além do download do modelo.
Tem para Mac ou celular?
Ainda não. Se você precisa, conte para a gente: isso define o que vem a seguir.
